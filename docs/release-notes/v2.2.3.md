## HGhubX 2.2.3

2.2.2 之后的测试版本：集中整理「我的」内容管理和吃瓜详情稳定性，本轮不包含 #170 的移动播放界面改动。

### 新增

- **收藏与观看历史批量管理**（#168）：在「我的」中，手机长按或电脑右键卡片进入多选；确认后取消所选收藏或删除所选观看记录，未选中的内容保留。收藏部分失败时保留失败项供重试。

### 改进

- **列表自动加载**（#169）：收藏和观看历史接近列表底部时自动继续加载，每次扩展 12 项；保持原有网格列数，不再需要点击「加载更多」。

### 修复

- **吃瓜详情闪烁**（#165）：切线或保存代理时保留已显示的正文与滚动位置，后台读取失败不清空旧播放地址；正文不变时复用图片节点，减少滚动时配图闪现和布局跳动。短暂缓冲延迟显示加载动画，主动跳转与重试仍立即反馈。
- **本人主页关注入口**：进入自己的主页时隐藏「关注」按钮，并拦截对本人的关注操作；其他创作者主页的关注入口保持不变。
- **批量取消收藏的账号隔离**（#168）：每项操作都核对开始时的账号与线路状态；切换账号、线路/代理变化或页面卸载后停止尚未发送的项目，不显示旧批次结果。

### 已知限制

- 本轮只生成测试安装包，不发布 GitHub Release；#170 的播放界面改动与相关样式整理留在原暂停分支。
- Android 版本为 `2.2.3`，`versionCode=2002003`；标准版与 TV 版分别提供安装包。同版本旧测试包需以本轮产物重新覆盖安装，界面版本号不能区分两者。
- iOS 包为未签名 IPA，需要自行签名侧载；macOS 包采用 ad-hoc 签名。
- 收藏「新更 N 集」基线仍按设备本地记录，不跨设备同步。
